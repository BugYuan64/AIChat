# Icon asset provenance

The PNG files in this directory and `../tab/` are generated by
`scripts/gen-ui-icons.mjs` from the Lucide icon set distributed through
`@iconify-json/lucide`.

- Lucide: ISC License, <https://lucide.dev/license>
- Iconify tooling: MIT License, <https://iconify.design/docs/license/>

The generated PNG files contain no remote runtime dependency. Run
`npm run icons:generate` after changing the icon catalog.

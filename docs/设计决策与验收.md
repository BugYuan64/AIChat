| 决策 | 本项目采用的设计默认与理由 | 备选及重新评估条件 |
| --- | --- | --- |
| D-01 客户端 | 传统 uni-app+Vue 3+TypeScript，Android 优先并复用业务 | 原生或 Flutter 在插件/性能实测不满足时评估；不混为 uni-app x |
| D-02 服务端 | ~~NestJS 模块化单体，Node.js LTS+TypeScript~~ **已修订（2026-10-25）**：Python+FastAPI 模块化单体 + SQLAlchemy async，连接器同为 Python | **用户于 2026-10-25 批准改用 Python**：实现已成、并发/恢复逻辑经测试验证，换语言零功能收益；连接器+服务端同语言统一。原 NestJS 备选保留，若前后端类型共享成为刚需再评估 |
| D-03 持久化 | PostgreSQL 事务、outbox、run 租约队列 | 内存队列不能恢复；外部消息队列按真实积压再引入（实施：开发/测试 SQLite，生产 PostgreSQL） |
| D-04 传输 | REST 命令/查询+标准 WSS JSON | Socket.IO 有独立 framing，不与本契约混用 |
| D-05 AI 桥接 | 本地 runner 主动出站，adapter 映射不同运行时 | 直接暴露 CLI/实验 WS 不作为默认；纯模型 API 仅声明实际能力 |
| D-06 身份 | account/actor 同一身份，human/agent 子型，owner 独立管理 | 厂商名/共享机器人账号无法隔离实例，不采用 |
| D-07 配对 | 短期公开扫码引用、秘密设备兑换、人类批准 | QR 带永久 token 会扩大泄漏，不采用 |
| D-08 调度 | human 显式触发，协作默认关闭 | AI 互相提及自动执行会失控，禁止作为默认 |
| D-09 恢复 | 至少一次+幂等+fence，结果未知停止自动执行 | 外部副作用无法靠数据库保证 exactly-once |

这些是文档作者依据任务采纳的默认，不把“推荐”写成用户已最终审批。
**修订记录**：2026-10-25 用户批准 D-02 改用 Python+FastAPI（实现分支技术栈），其余 D-01、D-03~D-09 维持；实施契约与本文的术语/数值差异集中在 [contracts/PROTOCOL.md §11](../contracts/PROTOCOL.md) 批准差异清单。
避免前期强塞 Redis/Kafka/K8s，组件触发条件见[目标架构](../项目最终架构.md)。

## 数值默认与调整责任

| 参数 | 设计默认 | 调整前检查 |
| --- | --- | --- |
| pairing 有效/轮询 | 5 分钟 / 5 秒 | 防暴力、设备体验、并发兑换 |
| user_code | 8 位易读字符 | 码空间、限速和短期唯一 |
| runner token / human WSS ticket | 10 分钟 / 30 秒一次性 | 撤销即时性、受众与安全存储 |
| 心跳/离线判定 | 20 秒 / 60 秒 | 移动前后台和断线恢复 |
| lease / dispatch ACK | 60 秒 / 10 秒 | 不把 ACK 当执行许可 |
| 未开工领取次数 | 最多 3 次 | 新 epoch，不重放未知写操作 |
| 排队/执行/取消确认 | 10 分钟 / 5 分钟 / 15 秒 | 上游硬取消和 unknown 展示 |
| runner/agent 并发 | 每 runner 2 / 每 agent 1 | 运行时会话隔离及资源占用 |
| 单条消息 AI 目标 | 最多 3 个 | 每个目标独立 run 与权限 |
| 协作链 | 4 轮、并发 2、20,000 token、10 分钟 | 可计量预算、原子预留与整链停止 |
| 事件/片段留存 | 7 天 / 24 小时 | 过期 resync 与快照恢复 |
| 帧/发送缓冲 | 64 KiB / 每连接 1 MiB | 背压停止读取和重拉能力 |

这些数值不代表性能承诺或上游限制，均由后续实测与产品确认调整；API 字段名称不随数值调整而变化。

## 安全部署与发布门槛

后端独立部署，TLS 入口开放 HTTPS/WSS，PostgreSQL 位于私网；runner 只主动出站，不公开设备 CLI。
human、runner、运维凭据分离，访问票据校验 audience、有效期、版本与撤销；摘要存储不代表无需保护数据库。
生产保护材料与厂商秘密不得进仓库、日志、二维码或聊天消息；本文不包含真实凭据或本机配置。
设备 runtime 的工作区、文件、命令、网络与推送能力需强制隔离和审批，无法强制就关闭相应能力。
提示注入只是不可信任务输入，不能改变平台成员、预算、owner 或工具授权。
服务端逐次做对象授权，群成员变化须使已排队事件/任务及时失效，不能只依赖 UI 隐藏按钮。
Web 内容安全渲染，限制不可信链接/HTML；H5 重新设计 Origin/CORS、票据和存储，不能复制 App 的假设。
审计只存行为与摘要，错误脱敏；通知不包含群正文，除非未来明确授权并验收隐私设置。
首期需要连接数、outbox 积压、排队时长、lease 超时、unknown 数、鉴权拒绝和背压指标，阈值在压测后确定。
备份与恢复在隔离环境演练：核对消息/成员/读游标一致，先停调度并失效旧租约，再处理未知副作用。
数据库变更先备份并在预发布验证，优先兼容增量变更；存在不可逆数据变更时不能只靠回退程序二进制恢复。
上线前记录部署版本、依赖版本、实际配置模板、恢复步骤和真实启动入口；本轮均未提供或执行。
后台通知、移动系统限制、小程序发布规则和必要合规事项届时单独核对，不复制未经验证的法律结论。

## 上游事实与来源边界

父 Hermes 已于 2026-10-24 实际检索并获取以下正文；本执行者按提供材料引用，没有再次联网核验。
uni-app 官方教程支持跨端框架和平台差异的设计依据，不等于完全免适配。[1]
Nest 官方说明 WsAdapter 基于 ws、兼容原生 WebSockets，可用 messageParser 转换默认 event/data；Socket.IO framing 不可混用。[2]
RFC 8628 区分 device_code、user_code、验证地址、有效期与轮询间隔；本项目只借鉴设备批准流程，不宣称完整 OAuth 实现。[3]
Hermes 官方 API server 提供 OpenAI-compatible HTTP 与会话能力；候选桥接仍须核对版本及所需功能，不代表完整工具执行或本机已启用。[4]
Codex 官方 app-server 采用双向 JSON-RPC 风格消息、wire 省略 jsonrpc 头，默认 stdio JSONL，WebSocket 标为 experimental/unsupported；本项目计划本地封装 stdio。[5]
Z.AI 官方 ZCode 页面可确认产品与配置来源，不能据此推断通用扫码 API、取消或审批协议。[6]
Claude/Gemini 的当前可用 API 不在本次已给证据内，本文不作事实推断；所有未列事实的方案均是本项目设计或待验证事项。
官方资料访问成功、CLI auth login、平台配对成功、runner 在线与真实 AI 任务验收是五种不同证据，不能互相替代。

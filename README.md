# AIChat

一个让人类用户与 AI 使用独立账号、通过私聊和群聊协作的聊天应用。名称暂沿用当前目录名；与 AgentForge 的产品归属尚未确定。

**当前阶段：初期设计，尚未开发。** 本次只有 Markdown 设计文档，没有项目源码、应用骨架、依赖安装、数据库或可运行服务。

## 已确定的方向

- 先开发手机 App，首个交付目标建议为 Android；H5、微信小程序后续适配。
- 人类和 AI 都有自己的账号、资料、联系人与会话身份，支持私聊和创建群聊。
- 统一 AI 接入包含**模型 API + 外部 Agent 连接器**，该范围已由用户确认。
- 外部 Agent 可采用“连接器展示二维码，App 扫码并确认”的方式绑定。
- 本次只完成设计构造，不编写项目代码。

## 建议方案

客户端采用 uni-app + Vue 3 + TypeScript；后端采用 Python + FastAPI 的模块化单体；PostgreSQL 保存账号、消息、运行任务和可靠事件。独立 worker 执行模型调用，外部连接器主动连接后端，运行于 Windows 或 Linux。

这是设计建议，技术栈尚未通过原型验证或锁定版本。AI 账号不等于模型名称，也不等于某个 CLI 进程；后端以统一运行协议衔接不同执行方式。Hermes、Codex、Claude、Gemini、ZCode 的实际适配方式与可用性，分别在后续接入阶段核验，不预先声明已经兼容。

uni-app 提供跨端能力，但平台接口仍有差异；例如官方扫码接口目前列出 App 支持、H5 不支持，因此 H5 的手动配对码或其他扫码实现须单独适配。参见 [Vue 3 支持](https://uniapp.dcloud.io/tutorial/vue3-basics)、[扫码接口](https://uniapp.dcloud.net.cn/api/system/barcode.html)。
